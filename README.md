# SweetGlam - Habesha Atelier

An elegant e-commerce web application that showcases and sells Habesha-inspired fashion and handmade products.

🔗 [Visit Website](https://ecommerce-website-101.netlify.app)

## Features
- Product listing and browsing
- Modern UI with responsive design
- Smooth navigation with TanStack Router
- Clean component-based architecture

## Tech Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- TanStack Router
